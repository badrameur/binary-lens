Local analysis API

The frontend and Python API share one origin. No API key is needed.

POST /api/analyze

Send a multipart form with a field named file. Optional model_variant: pretrained (default) or student (ELF only). Maximum file size: 20 MiB. Analysis runs in a child process with a 60 second wall timeout.

curl -F 'file=@/path/to/example.exe' http://127.0.0.1:8000/api/analyze

Returns JSON with file identity, structure, prediction, feature contributions, an actual tree path, observations, strings, and visual data. Unsupported formats receive byte inspection without a prediction.

Status codes: 200 success; 400 empty file or unknown model; 408 timeout; 413 size limit; 422 analysis or request error. A 200 response can contain prediction.available: false; callers must check this field.

GET /api/status

Returns model-file availability, maximum upload size, and measured evaluation results when present.

GET /api/demo

Downloads a fixed, harmless Linux sample. It does not read arbitrary local paths.
